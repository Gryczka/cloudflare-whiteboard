A collaborative whiteboard on Cloudflare

Draw, write, and collaborate in real time. A SQLite-backed Durable Object orders changes for each board; hibernatable WebSockets synchronize collaborators. Separate edit and view links control access, and inactive boards expire after 30 days by default.

This public introduction works without JavaScript. Creating a board is a deliberate action in the app above. Keep capability links private.
