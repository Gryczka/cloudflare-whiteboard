# Support

This project is shared as a reference sample. It is not actively supported and there is no guaranteed response time.

- Read the [README](README.md) for setup, architecture, and known limitations.
- Use GitHub Issues for reproducible bugs and focused feature proposals.
- Use GitHub private security advisories for vulnerabilities.
- Use the [Cloudflare Developers Discord](https://discord.cloudflare.com/) for general platform questions.

Never post a live board capability link in a public support request.
