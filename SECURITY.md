# Security Policy

## Supported versions

| Version                 | Supported |
| ----------------------- | --------- |
| Current `main`          | Yes       |
| Older commits and forks | No        |

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private security advisory flow. Do not open a public issue containing capability links, exploit details, or board content.

Reports should include impact, reproduction steps, and suggested mitigations when available. Receipt will be acknowledged within 48 hours on a best-effort basis. Critical fixes are targeted within seven days, but this reference project has no guaranteed response time.

Coordinated disclosure should occur only after a fix is available.
